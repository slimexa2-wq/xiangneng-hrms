# 祥能 HRMS 实施计划

详细的测试驱动执行步骤位于：

- `docs/superpowers/plans/2026-07-26-full-hrms-production.md`

执行顺序：

1. 安全建立公开源码基线和合成数据；
2. 扩展组织、内部员工、多角色和数据范围；
3. 建设报销七态领域、API和文件输出；
4. 补齐领导看板、现场运营、员工、供应商和招聘联动；
5. 接入本地 Qwen3.5 4B 并完成降级；
6. 完成 PC、Portal 和 Taro 界面；
7. 修复 Docker、公开部署和微信上传准备；
8. 运行全部静态检查、自动化测试、构建和浏览器验收；
9. 创建正常源码 Pull Request，不合并 `main`。

所有业务功能按测试先行实现。每项验收未通过前不得标记为完成。
