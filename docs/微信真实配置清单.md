## 2. 服务端环境变量

| 变量 | 必填阶段 | 说明 |
|---|---|---|
| `WECHAT_MINIAPP_APP_ID` | 小程序登录联调 | 小程序 AppID |
| `WECHAT_MINIAPP_APP_SECRET` | 小程序登录联调 | 仅服务端使用 |
| `WECHAT_OFFICIAL_APP_ID` | 公众号通知联调 | 已认证服务号 AppID |
| `WECHAT_OFFICIAL_APP_SECRET` | 公众号通知联调 | 仅服务端使用 |
| `WECHAT_TEMPLATE_APPLICATION_SUCCESS` | 报名通知 | 报名成功模板 ID |
| `WECHAT_TEMPLATE_INTERVIEW_REMINDER` | 面试通知 | 面试提醒/结果模板 ID；如平台模板不同应拆分变量 |
| `WECHAT_TEMPLATE_EMPLOYMENT_STATUS` | 入离职/推荐通知 | 入职、离职或推荐状态模板 ID；按实际审核模板拆分 |
| `WECHAT_TEMPLATE_SALARY_PUBLISHED` | 工资条通知 | 工资条发布模板 ID |
| `WECHAT_TEMPLATE_JOB_DEMAND` | 新招聘需求 | 向关联项目的活跃供应商发送新需求模板 ID |
| `WECHAT_MINIAPP_PATH` | 消息跳转 | 默认小程序入口；业务消息应附带详情页参数 |

模板字段必须以微信公众平台实际选用并审核通过的关键词为准，不能把示例字段名直接当成生产模板。

## 3. 小程序登录链

1. 小程序端调用 `wx.login()` 获得临时 `code`；
2. `code` 发送到本系统服务端 `/api/wechat/auth/login`；
3. 服务端使用 AppID、AppSecret 和 `code` 调用微信 `/sns/jscode2session`；
4. 服务端用返回的 OpenID/UnionID 匹配或发起人员身份绑定，随后签发本系统会话；
5. `session_key` 只保留在服务端受控存储，不返回前端、不写日志；
6. 首次绑定必须再校验人员身份，不能仅凭前端传入的人员 ID、手机号或角色建立权限。

官方依据：

- https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/login.html
- https://developers.weixin.qq.com/miniprogram/dev/OpenApiDoc/user-login/code2Session.html

## 4. 服务器域名与 HTTPS

- [ ] 在“小程序后台 → 开发 → 开发设置 → 服务器域名”配置生产 API 域名；
- [ ] `request` 合法域名覆盖业务 API；
- [ ] `uploadFile` 合法域名覆盖人员附件与项目实拍图上传；
- [ ] `downloadFile` 合法域名覆盖附件、导出文件和项目图片下载；
- [ ] 如启用 WebSocket，再单独配置 `wss` 域名；本期普通业务不要求 WebSocket；
- [ ] 域名使用有效 HTTPS 证书，配置的端口与实际请求完全一致；
- [ ] 生产环境关闭开发者工具中的“不校验合法域名”选项后再验收；
- [ ] CORS 仅允许正式管理端域名，文件访问使用鉴权或短期签名地址。

官方依据：https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html
