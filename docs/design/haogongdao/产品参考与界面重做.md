# 好工到产品参考与界面重做

调研日期：2026-10-03。范围：四川省内工厂普工、仓储物流招聘，微信小程序及 HRMS 招聘后台。

本轮实际读取鱼泡直聘、吉工家、快马日结的中国区 App Store 页面、公开商店截图和开发者说明，并读取 BOSS 直聘、58 同城官方首页。商店截图包含营销展示，与登录后的真实交互有区别；产品说明中的用户规模、审核效果和响应速度属于平台自述，没有用作本项目的效果承诺。

## 信息结构

手机首页按「搜索 → 工种 → 城市与待遇 → 招聘岗位」组织。全省入口优先展示，具体城市由用户选择，页面不声称已经取得定位或计算岗位距离。

主要导航统一为「找工作、我的报名、推荐有奖、我的」。本人报名可直接进入；进入报名页面时只高亮该入口，进入个人资料及帮助页面时高亮「我的」。员工推荐使用原有授权和真实推荐关系。

岗位卡片显示岗位名、工资与计薪单位、地点与班次、已填写福利、所属项目和报名操作。数字薪资放大，复杂工资说明按完整原文正常字号展示；不把小时或日薪换算成月薪。详情保留工资条件、工作内容、要求、奖励条件与电话咨询。

小程序报名记录新增报名、面试、入职阶段展示，具体状态仍以该次报名记录为准。个人中心先展示本人身份和服务入口，账号绑定、刷新、切换和退出集中在「账号与设置」中。

后台提供岗位发布、报名跟进、奖励规则、奖励发放四个业务入口。岗位页增加招聘概况与发布状态筛选：概况汇总当前账号获准查看的全部岗位，不把当前分页当成全局数量；按岗位累计的报名和入职数标为人次。统计读取失败时显示缺失并提供重试。发布、编辑和上下架后同时刷新列表与概况。

## 视觉与可操作性

采用冷灰背景、白色 14–18px 圆角内容卡、蓝色主要操作、橙色薪资；工种使用小面积色底与线条图标。去掉过大的灰白薪资卡及满宽卡片报名按钮，让信息更容易连续比较。

手机上岗位标题约 19px、工资 28px、地点班次与项目名 13px；报名按钮至少 44px 高。工种与城市均有选中状态，按钮有键盘焦点样式。原生小程序使用对应的 750px 设计稿尺度和安全区底部间距。

390px 和 1440px 的浏览器页面完成筛选、详情、报名、进度查询、推荐邀请与后台管理检查。另检查 320、375、390、430px 的适配；小屏可滚动阅读，375px 及以上的测试尺寸可在首屏看完整报名按钮。

## 本轮验证

- 原生小程序：35 项测试、类型检查、微信构建通过。
- Portal：16 项测试、类型检查、生产构建通过。
- 管理后台：35 项测试、类型检查、lint、生产构建通过。
- 浏览器：33 项主流程与 6 项账号权限检查通过，未发现 JavaScript 页面错误。
- 补充适配检查：320、375、390、430px 无文档横向溢出；375px 及以上测试尺寸的首个报名按钮不被底部导航覆盖。

浏览器截图采用明确标示的合成演示数据；原生微信构建产物另行提供开发预览包。实际微信登录、真机效果和平台发布需要配置真实 AppID、服务端凭证与合法 HTTPS 域名。

本轮业务接口的基线验证见 [集成测试报告](../../reports/bluecollar-test-report.md)，包含 2026-10-02 的真实 PostgreSQL 报名、推荐奖励及身份绑定场景。
