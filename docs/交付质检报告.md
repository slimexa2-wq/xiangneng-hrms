- 公开演示只包含确定性合成数据，未把 Downloads 中的真实人员表打入网站或仓库。
- 内部授权查询按用户真实权限返回完整字段；数据安全依赖认证、授权、范围和审计，而不是前端脱敏。
- 模型运行在本机 Ollama，不把系统人员数据发送给第三方模型服务。
- 模型没有 SQL 能力，不能绕过业务服务修改数据库。
- 写操作预览不落库，确认前后均有权限和状态复核。

- 微信正式上传仍需要用户自己的 AppID、主体认证、合法域名和腾讯侧发布权限。
