# 祥能AI业务助手 Skill 包

本包用于指导 Codex 在现有“祥能人员与招聘信息管理系统”中新增 AI 业务助手，并作为本地大模型进行意图识别、参数标准化、工具调用和风险控制的统一依据。

## 当前固定能力

1. 查询项目人员数据；
2. 查询人员信息与当前状态；
3. 查询项目招聘进度；
4. 办理单个人员入职；
5. 办理单个人员离职。

## 核心原则

- 规则优先，模型兜底；
- 模型只理解人话，程序负责查数、算数和执行；
- 禁止自由 SQL 和模型直接写数据库；
- 查询直接执行，写操作先预览、后确认；
- 权限继承现有系统并由后端再次校验；
- 同名、歧义和缺失参数时停止执行；
- 事务、幂等、审计日志和演示数据隔离必须实现；
- 模型异常时降级为标准表单，传统系统继续可用。

## 使用方式

将本目录放入现有项目，例如：

```text
docs/ai-skills/xiangneng-ai-business-assistant/
```

将根目录 `CODEX_PROMPT.md` 作为 Codex 主任务提示词。运行时按需加载总提示词、路由配置和命中的单个 Skill，避免把全部文件一次塞给小模型。
