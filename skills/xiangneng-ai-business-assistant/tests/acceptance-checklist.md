# 验收清单

## 路由
- [ ] 五项 Skill 标准表达、口语表达均可识别；
- [ ] 入职人数不触发办理入职；
- [ ] 离职人数、离职政策、为什么想离职不触发办理离职；
- [ ] 低置信度会澄清；
- [ ] 不支持业务不会创造工具。

## 数据
- [ ] 所有数字来自现有业务服务；
- [ ] 入职、离职、在职、缺口口径与传统页面一致；
- [ ] 结果含范围、口径、更新时间；
- [ ] 不编造缺失月份。

## 权限
- [ ] 后端重新校验角色和数据范围；
- [ ] 供应商仅看自己输送人员；
- [ ] 员工仅看本人；
- [ ] 领导默认无写权限；
- [ ] 越权请求留痕。

## 写安全
- [ ] 入职、离职先预览；
- [ ] 预览不写数据库；
- [ ] 同名必须选择；
- [ ] action_token 有效期；
- [ ] 幂等防重复；
- [ ] 事务失败回滚；
- [ ] 操作前后写日志；
- [ ] 不支持批量写。
