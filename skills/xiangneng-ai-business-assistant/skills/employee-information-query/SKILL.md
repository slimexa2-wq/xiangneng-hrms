# 人员信息与状态查询 Skill

## Skill ID
`employee_information_query`

## 目标
按姓名、手机号、编号或手机号尾号查询人员状态、项目、入离职时间、供应商、推荐人和生命周期。

## 典型触发
- 现在还在职吗
- 在哪个项目
- 什么时候入职
- 什么时候离职
- 谁推荐的
- 手机号尾号

## 禁止误触发
- 办理入职
- 办理离职
- 状态改成

## 必填参数
- `employee_identifier`

## 可选参数
- `fields`

## 权限
供应商仅看自己输送人员，员工仅看本人，内部人员按分公司和项目范围。

## 工具
- `search_employee`
- `get_employee_detail`

## 标准流程
1. 识别意图和参数；
2. 解析项目、人员和日期；
3. 校验 Schema；
4. 校验当前登录用户权限；
5. 校验业务规则；
6. 查询直接执行，写操作仅生成预览；
7. 写操作收到用户确认后通过正式服务提交；
8. 返回结构化结果并写审计日志。

## 业务校验
- 同名必须返回脱敏候选
- 手机号必须脱敏
- 不得向无权限用户暴露候选
- 必须区分当前状态与历史状态

## 失败处理
- 未找到：明确返回未找到；
- 多个实体：返回脱敏候选；
- 缺参：只询问缺少项；
- 无权限：后端拒绝，不允许模型绕过；
- 模型异常：切换标准表单；
- 写操作超时：查询 action 状态，不盲目重复执行。
