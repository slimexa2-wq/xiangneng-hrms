# 意图路由 Skill

## 顺序

1. 读取真实登录角色和数据范围；
2. 用强关键词、弱关键词和排除词匹配；
3. 强规则唯一命中时直接路由；
4. 多重命中或口语表达时调用模型；
5. 模型必须输出 `intent-schema.json`；
6. 置信度低于 0.72 时澄清；
7. 写操作再次检查负触发词；
8. 只向模型提供命中 Skill 相关的 2 至 4 个工具。

## 必须区分

- “四川时代1月入职多少人” → 人员统计；
- “张三什么时候入职” → 人员信息；
- “给张三办理入职” → 入职操作；
- “本月离职多少人” → 人员统计；
- “张三为什么想离职” → 不支持，不得写；
- “张三今天离职，原因是……” → 离职操作。
