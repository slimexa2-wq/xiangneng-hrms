# 实施计划

## 阶段1：仓库审查与业务映射
完成技术栈、权限、实体、入离职和统计服务映射。验收：五项Skill均找到正式服务或明确缺口。

## 阶段2：只读MVP
实现规则路由、模型结构化分类、人员搜索、项目统计、招聘进度和权限。验收：三项查询与传统页面一致。

## 阶段3：写操作预览
实现同名选择、参数补齐、状态校验、权限和预览卡。验收：预览数据库无变化。

## 阶段4：确认执行
实现幂等、事务、正式入离职服务、日志和状态查询。验收：重复确认不重复写，失败完整回滚。

## 阶段5：稳定性与演示
实现预热、健康检查、超时、熔断、降级、一键重置和演示脚本。验收：断网可完成核心演示。
